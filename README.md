# Калькулятор Лема

Интерактивный конструктор сюжета романа по методу Станислава Лема. Приложение предлагает волны развилок сюжета, вы выбираете вариант — и так, шаг за шагом, собирается роман из 12 уровней: от завязки до эпилога. Есть карта-дерево со всеми альтернативными ветками, автоматический «режим Лема» и экспорт романной библии в Markdown и DOCX.

Приложение работает **полностью локально**: сюжеты и настройки хранятся в базе SQLite на вашем диске, API-ключи шифруются (AES-256-GCM) и никогда не покидают компьютер.

---

## Быстрый запуск (Windows)

1. Установите **Node.js LTS** (версия 20 или новее), если ещё не стоит: <https://nodejs.org/> — кнопка «LTS», далее «Далее» до конца. Это единственная разовая подготовка.
2. Дважды щёлкните **`start.bat`**.
3. Что произойдёт:
   - при **первом запуске** скрипт сам установит зависимости (несколько минут, нужен интернет), создаст базу и запустит сервер;
   - затем через **3 секунды** сам откроет браузер на адресе <http://localhost:3000>. Если первый запуск был долгим и страница ещё не готова — просто обновите её (F5), сервер уже запущен.
4. При следующих запусках всё стартует за несколько секунд.

> Если Windows SmartScreen предупреждает о start.bat — нажмите «Подробнее» → «Выполнить в любом случае». Это обычный текстовый файл команд, он только запускает сервер и открывает браузер.

**Остановка приложения:** закройте свёрнутое окно «Калькулятор Лема — СЕРВЕР». Данные при этом никуда не денутся.

**После обновления файлов проекта** просто запустите `start.bat` (или `restart.bat`) — скрипт сам применит обновления структуры базы данных (`prisma db push`), данные проектов при этом сохраняются.

**Если приложение ведёт себя странно** (ошибки «HTML вместо JSON» или «HTTP 404» при нажатии кнопок, белый экран, кнопки не реагируют) — дважды щёлкните **`restart.bat`**: он остановит сервер, удалит кэш сборки `.next` и запустит всё заново, снова открыв браузер. Такое случается, когда файлы проекта обновлялись при работающем сервере.

## Запуск вручную (macOS / Linux, или без start.bat)

В папке проекта выполните:

```bash
npm install        # один раз, установка зависимостей
npx prisma generate # один раз, клиент базы данных
npm run dev        # запуск сервера
```

и откройте <http://localhost:3000>. Остановка — Ctrl+C в терминале.

## Первый запуск в приложении

Приложение попросит выбрать **провайдера языковой модели** — тот «мозг», который будет придумывать развилки:

| Провайдер | Ключ | Кому подходит |
|---|---|---|
| **AIAI.BY (400+ моделей)** | нужен, с <a href="https://aiai.by">aiai.by</a> | Доступ к GPT, Claude, Gemini, DeepSeek и другим в одном ключе; оплата в BYN, без VPN. Список моделей подтягивается с сайта автоматически (кнопка ⟳ у поля «Модель») |
| OpenAI, Anthropic Claude, DeepSeek, Z.ai GLM | нужен, у соответствующего провайдера | Если есть ключ напрямую у этих сервисов |
| Ollama (локально) | не нужен | Модели работают на вашем компьютере; требуется установленный [Ollama](https://ollama.com) |
| Демо-шаблоны (офлайн) | не нужен | Заготовленные сюжетные развилки без сети и расходов — просто посмотреть, как всё устроено |

API-ключ вставляется один раз, шифруется и хранится только на вашем компьютере. Провайдера можно сменить в любой момент в «Настройках».

## Где хранятся данные

- `db/custom.db` — база SQLite: проекты, дерево сюжета, настройки, шифрованные ключи.
- Резервная копия — просто скопируйте папку `db` (при остановленном приложении).
- Приложение не отправляет ваши тексты и ключи никуда, кроме выбранного вами провайдера модели.

## Частые проблемы

| Проблема | Решение |
|---|---|
| «Node.js не найден» | Установите Node.js LTS 20+ с <https://nodejs.org/> и запустите start.bat снова |
| Первый запуск «висит» на установке | Это npm ставит зависимости — дождитесь окончания, нужно несколько минут и интернет |
| Браузер открылся с ошибкой «не удаётся получить доступ к сайту» | Сервер ещё собирает страницу первого запуска — подождите до минуты и нажмите F5 |
| Порт 3000 занят другим приложением | Запустите вручную на другом порту: `npx next dev -p 3001` и откройте <http://localhost:3001> |
| Ошибка при установке зависимостей | Удалите папку `node_modules` и запустите start.bat снова |
| Сгенерированная волна выдаёт ошибку провайдера | Проверьте ключ кнопкой «Проверить подключение» в настройках; при ошибке 429 провайдер перегружен — подождите минуту |
| «Сервер приложения ответил HTML вместо JSON» / «HTTP 404» при нажатии кнопок | Запустите `restart.bat`; если не помогло — скопируйте папку проекта заново (в ней должен быть файл `src\app\api\settings\test\route.ts`) |
| «Нет соединения с сайтом провайдера» при обновлении списка моделей | Разовый сетевой сбой — нажмите кнопку ⟳ ещё раз через минуту; проверьте, что интернет работает и адрес в поле «Базовый URL» — `https://api.aiai.by/v1` |
| Ошибка «self-signed certificate in certificate chain» / «unable to verify the first certificate» | HTTPS-трафик перехватывает антивирус или прокси (подмена сертификата). Обновите файлы проекта — приложение само выполнит подключение в обход подменённого сертификата (только для запросов к провайдеру). Строгая проверка для остальных соединений сохраняется |
