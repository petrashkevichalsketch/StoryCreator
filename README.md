\# 📖 Калькулятор Лема



Интерактивный конструктор сюжета романа по методу Станислава Лема. Приложение предлагает волны развилок сюжета, вы выбираете вариант — и так, шаг за шагом, собирается роман из 12 уровней: от завязки до эпилога. 



Есть карта-дерево со всеми альтернативными ветками, автоматический «режим Лема» и экспорт романной библии в Markdown и DOCX.



Приложение работает \*\*полностью локально\*\*: сюжеты и настройки хранятся в базе SQLite на вашем диске, API-ключи шифруются (AES-256-GCM) и никогда не покидают компьютер.

\## ✨ Основные возможности



\- \*\*Пошаговое построение сюжета\*\*: 6 актов, 12 уровней, 8 жанровых категорий.

\- \*\*Интеграция с LLM\*\*: Поддержка OpenAI, Anthropic, DeepSeek, Z.ai, AIAI.BY и локальной Ollama.

\- \*\*Демо-режим\*\*: Офлайн-шаблоны для знакомства с интерфейсом без API-ключей.

\- \*\*Карта сюжета\*\*: Визуализация дерева решений с возможностью возврата к альтернативным ветвям.

\- \*\*Режим Лема\*\*: Автоматическая генерация и выбор развилок в заданном темпе.

\- \*\*Экспорт\*\*: Выгрузка готовой библии романа в `.md` и `.docx` с учетом статистики и альтернатив.

\- \*\*Приватность\*\*: Ключи шифруются, база данных локальная, никакой телеметрии.

\## 🚀 Быстрый запуск (Windows)



1\. Установите \*\*Node.js LTS\*\* (версия 20 или новее), если он ещё не установлен: \[nodejs.org](https://nodejs.org/).

2\. Скачайте проект и дважды щёлкните \*\*`start.bat`\*\*.



\*\*Что произойдёт при первом запуске:\*\*

\- Скрипт автоматически установит зависимости, создаст базу данных и запустит сервер (потребуется несколько минут и интернет).

\- Через 3 секунды автоматически откроется браузер на адресе `http://localhost:3000`. Если страница ещё не готова — просто обновите её (F5).



> Если Windows SmartScreen предупреждает о `start.bat` — нажмите «Подробнее» → «Выполнить в любом случае».



\*\*Остановка приложения:\*\* закройте свёрнутое окно «Калькулятор Лема — СЕРВЕР».



\*\*Если приложение ведёт себя странно\*\* (ошибки «HTML вместо JSON» или «HTTP 404», белый экран, не реагируют кнопки) — дважды щёлкните \*\*`restart.bat`\*\*. Он остановит сервер, очистит кэш сборки `.next` и запустит всё заново.

\## 💻 Запуск вручную (macOS / Linux)



В папке проекта выполните:



```bash

\# Установка зависимостей (один раз)

npm install

npx prisma generate



\# Запуск сервера разработки

npm run dev

```



Откройте \ [http://localhost:3000] (http://localhost:3000). Для остановки нажмите `Ctrl+C` в терминале.

\## ⚙️ Настройка провайдеров



При первом запуске приложение попросит выбрать \*\*провайдера языковой модели\*\*:



| Провайдер | Ключ | Особенности |

| :--- | :--- | :--- |

| OpenAI, Anthropic, DeepSeek, Z.ai | Нужен | Прямые ключи от соответствующих сервисов. |

| Ollama (локально) | Не нужен | Требуется установленный \[Ollama](https://ollama.com). Работает полностью офлайн. |

| Демо-шаблоны | Не нужен | Заготовленные сюжетные развилки без сети и расходов. |



API-ключ вставляется один раз, шифруется и хранится только на вашем компьютере. Провайдера можно сменить в любой момент в «Настройках».



\---



\## 📂 Где хранятся данные



\- `db/custom.db` — база данных SQLite (проекты, дерево сюжета, настройки, шифрованные ключи).

\- \*\*Резервная копия\*\* — просто скопируйте папку `db` при остановленном приложении.

\- Приложение не отправляет ваши тексты и ключи никуда, кроме выбранного вами провайдера модели.

\## 🩺 Частые проблемы (Troubleshooting)



| Проблема | Решение |

| :--- | :--- |

| «Node.js не найден» | Установите Node.js LTS 20+ с \[nodejs.org](https://nodejs.org/) и запустите `start.bat` снова. |

| Первый запуск «висит» на установке | Это npm ставит зависимости — дождитесь окончания (требуется интернет). |

| Браузер открылся с ошибкой «не удаётся получить доступ к сайту» | Сервер ещё собирает страницу — подождите до минуты и нажмите F5. |

| Порт 3000 занят другим приложением | Запустите вручную на другом порту: `npx next dev -p 3001` и откройте `http://localhost:3001`. |

| Ошибка при установке зависимостей | Удалите папку `node\_modules` и запустите `start.bat` снова. |

| Ошибка провайдера (429) | Провайдер перегружен — подождите минуту. Проверьте ключ кнопкой «Проверить подключение». |

| «Сервер приложения ответил HTML вместо JSON» / «HTTP 404» | Запустите `restart.bat`. Если не помогло — убедитесь, что структура файлов проекта (роуты в `src/app/api/`) не повреждена. |

| «Нет соединения с сайтом провайдера» | Разовый сетевой сбой при обновлении списка моделей. Проверьте адрес в поле «Базовый URL» (для AIAI.BY: `https://api.aiai.by/v1`). |

| Ошибка SSL: `self-signed certificate` / `unable to verify the first certificate` | HTTPS-трафик перехватывает антивирус или прокси. Приложение автоматически обходит подмену сертификата только для запросов к провайдеру (строгая проверка для остальных соединений сохраняется). |
